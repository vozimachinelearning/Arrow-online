System Requirements

  • OS: Windows 10 22H2+ or Windows 11
  • CPU: x64 with 4+ cores (8+ recommended)
  • RAM: 8 GB minimum, 16 GB+ recommended
  • Storage: 5 GB free space (models: ~3.5 GB)
  • GPU: Optional — CUDA for GPU offload
  • Runtime: No Python required (frozen build)
Installation Guide

Get up and running in 3 steps

1

Download the Installer

Click the download button above to get the latest Arrow MSI installer. The file is signed and verified.

2

Run the Installer

Double-click the MSI file and follow the setup wizard. Arrow installs to your Program Files directory. No admin rights required for per-user install.

3

Launch & Automate

Launch Arrow from your Start Menu. Models are downloaded automatically on first launch. Start recording workflows immediately.
